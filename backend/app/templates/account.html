Akun MetaTrader 5

Hubungkan akun MT5 follower untuk menyalin posisi yang dibuka oleh EA Algentra.

Token EA hanya terlihat saat dibuat atau dirotasi.

Hubungkan akun follower

Masukkan nama server broker dan nomor login MT5. Kami tidak meminta atau menyimpan kata sandi broker.

Akun yang terhubung

Hubungkan hingga 10 akun follower. Tanda hijau berarti token dan identitas akun berhasil diverifikasi oleh server dalam 30 detik terakhir, serta EA utama mengirim pembaruan dalam 20 detik terakhir. Tanda ini tidak memeriksa izin AllowLiveTrading atau Algo Trading di MT5.

Pasang EA follower

EA utama Algentra menjalankan sinyal dan mengirim posisi terbuka. EA follower menyinkronkan posisi tersebut ke akun MT5 yang Anda hubungkan.

Unduh EA follower
  1. Hubungkan akun MT5 di atas. Salin token yang muncul; token hanya terlihat saat dibuat atau dirotasi.
  2. Unduh EA follower. Di MT5, pilih File → Open Data Folder, buka folder MQL5/Experts, lalu salin file .ex5 ke sana. File siap dipakai tanpa compile.
  3. Di MT5, pilih Tools → Options → Expert Advisors, aktifkan Allow WebRequest for listed URL, lalu tambahkan https://algentracapital.my.id.
  4. Dari Navigator → Expert Advisors, pasang EA di chart. Isi AccountToken dengan token akun tersebut, pastikan ServerURL benar, lalu aktifkan Algo Trading.
  5. Pastikan EA utama Algentra aktif dan uji EA follower di akun demo. AllowLiveTrading nonaktif secara default. Atur VolumeMultiplier sesuai kebutuhan sebelum mengaktifkan trading live.

Arti pesan di chart MT5

HTTP -1 / ERROR 4006: EA belum mendapat jawaban dari server. Kode 4006 berarti MT5 menemukan data array yang tidak valid saat EA berjalan; pesan ini sendiri belum membuktikan token salah. Pastikan URL ServerURL sama dengan alamat yang diizinkan di Allow WebRequest. Jika masih muncul, kirim tangkapan tab Experts kepada dukungan. Jangan kirim token.

LIVE COPYING OFF: EA follower belum diizinkan membuka posisi live. Periksa opsi AllowLiveTrading pada input EA. Pengaturan ini terpisah dari koneksi server; uji lebih dulu di akun demo.

Akun follower harus memakai mode hedging. Volume salinan mengikuti volume sumber dikalikan VolumeMultiplier; nilainya tidak menyesuaikan ekuitas secara otomatis. Jika pembaruan dari akun utama terhenti lebih dari 20 detik, sinkronisasi berhenti. Posisi yang sudah terbuka tetap berada di MT5 jika EA berhenti.

Jangan bagikan token EA. Jika token hilang atau terekspos, pilih Rotasi token dan perbarui token di EA follower. Hanya posisi yang dibuat oleh EA utama Algentra yang disalin; posisi manual dan EA lain tidak ikut disinkronkan.
