Pasang EA Copy Trading

EA utama Algentra menerbitkan semua posisi terbuka, termasuk posisi yang dibuka manual dari MT5. EA Copy Trading juga mengirim saldo dan riwayat transaksi MT5 ke portal ini.

Unduh EA Copy Trading
  1. Hubungkan akun Copy Trading di atas. Salin token yang muncul; token hanya terlihat saat dibuat atau dirotasi.
  2. Unduh EA Copy Trading. Di MT5, pilih File → Open Data Folder, buka folder MQL5/Experts, lalu salin file .ex5 ke sana. File siap dipakai tanpa compile.
  3. Di MT5, pilih Tools → Options → Expert Advisors, aktifkan Allow WebRequest for listed URL, lalu tambahkan https://algentracapital.my.id.
  4. Dari Navigator → Expert Advisors, pasang EA Copy Trading di chart. Isi AccountToken dengan token akun tersebut, pastikan ServerURL benar, lalu aktifkan Algo Trading.
  5. Pastikan EA utama Algentra aktif dan uji EA Copy Trading di akun demo. AllowLiveTrading nonaktif secara default. Atur VolumeMultiplier sesuai kebutuhan sebelum mengaktifkan trading live.

Arti pesan di chart MT5

HTTP -1 / ERROR 4006: EA belum mendapat jawaban dari server. Kode 4006 berarti MT5 menemukan data array yang tidak valid saat EA berjalan; pesan ini sendiri belum membuktikan token salah. Pastikan URL ServerURL sama dengan alamat yang diizinkan di Allow WebRequest. Jika masih muncul, kirim tangkapan tab Experts kepada dukungan. Jangan kirim token.

LIVE COPYING OFF: EA Copy Trading belum diizinkan membuka posisi live. Periksa opsi AllowLiveTrading, Algo Trading, dan izin trading akun pada MT5. Uji lebih dulu di akun demo.

Akun Copy Trading harus memakai mode hedging. Volume salinan mengikuti volume sumber dikalikan VolumeMultiplier; nilainya tidak menyesuaikan ekuitas secara otomatis. Jika pembaruan dari akun utama terhenti lebih dari 20 detik, sinkronisasi berhenti. Posisi yang sudah terbuka tetap berada di MT5 jika EA berhenti.

Jangan bagikan token EA. Jika token hilang atau terekspos, pilih Rotasi token dan perbarui token di EA Copy Trading.
